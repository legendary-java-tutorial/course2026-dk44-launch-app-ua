# Release Day — стартовий застосунок модуля 6

Node.js-застосунок курсу Docker 2026: сторінка з привітанням і лічильником відвідувань.

- **Порт:** 3000.
- **Маршрути:** `/` — привітання й кількість відвідувань; `/crash` — завершує процес кодом 1 (для дослідів із політикою перезапуску).
- **Дані:** лічильник зберігається в `/data/counter.txt` — підключіть до `/data` іменований том, інакше лічильник зникне разом із контейнером.
- **Збирання образу:** `.github/workflows/build.yml` — запуск за міткою git `v*`, образ під `linux/amd64` і `linux/arm64`. Перед першою міткою впишіть у вхід `images` свій простір імен Docker Hub і створіть секрети `DOCKERHUB_USERNAME` і `DOCKERHUB_TOKEN` у налаштуваннях свого репозиторію.

Запуск без Docker Hub:

```bash
docker build -t app:dev .
docker run -d -p 8080:3000 -v data:/data --name app app:dev
```
